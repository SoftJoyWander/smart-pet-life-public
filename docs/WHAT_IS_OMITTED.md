# 這份公開版省略了什麼

這個 repo 是完整專案的節選。與其讓讀者自己猜哪裡缺了一塊，不如直接列清楚——
知道自己公開了什麼、沒公開什麼，本身也是工程判斷的一部分。

省略遵循一條界線：**能說明「怎麼想」的留下，能讓人直接複製成產品的拿掉。**

## 一、完全未收錄

### 模型權重與訓練配方

- 犬隻 Re-ID 的自訓 checkpoint、訓練腳本、取樣策略與損失設定。
- 便便影像辨識的模型、閾值校準流程與驗證證據。
- 犬隻在場判斷的 ONNX 模型。
- 訓練用的 Colab notebook 與超參數設定檔。

這是整個專案唯一真正不可替代的部分。模型本身的價值來自資料與反覆調整，
公開架構不等於公開能力，但公開權重就是直接交出成果。

### 私有資料集與實地評測

- 台灣本地蒐集的犬隻照片、標註與資料集清單。
- 以實際使用者照片量測 Top-K 與開集誤接受率的評測流程。

涉及第三方影像與個資，不適合公開，也無法在公開授權下重新散布。

### 犬隻協尋功能

協尋是這個專案技術難度最高的部分，但也最接近產品差異化，因此整塊未收錄：

- 案件、媒體、候選與線索的資料表、RLS 政策與受控 RPC。
- 協尋相關的 App 畫面與資料存取層。
- 比對流程的排程端與照片前置把關 Edge Function。
- 防冒領驗證機制的設計細節。

文件裡保留了高層次描述（做了什麼、為什麼這樣設計、守住哪些邊界），
移除了欄位定義、函式名稱與可照著實作的流程規格。

### 內部工作記錄

每日聊天記錄、工作日誌、開發環境遷移清單與本機測試腳本。
這些對外沒有閱讀價值，且包含尚未拍板的產品決策。

## 二、介面保留，實作換成公開 baseline

`ai/pet-reid/src/pet_reid_tool/inference.py` 的對外介面與正式版完全相同，
但實作換成 ImageNet 預訓練權重直接取特徵。

正式版與公開版的差異只有兩處：

1. 正式版讀取自訓 checkpoint 與 model card，比對 SHA-256，
   並確認這份權重沒有混入營運中的使用者照片。
2. 正式版在骨幹後面接自訓的投影層與 BatchNorm，輸出維度由訓練設定決定。

其餘的輸入驗證、EXIF 轉正、大小限制、正規化檢查與回應格式都一樣。
這樣保留的好處是：整條服務路徑可以實際跑起來、可以測試，
但複製過去沒有任何競爭力——換成別人的資料，準確度一樣不會好。

`server.py` 與 `cli.py` 同樣是公開版：拿掉了未公開模型的端點與訓練子指令，
保留的部分處理的都是公開資料集（Oxford-IIIT Pet、MPDD）。

## 四、這份節選是怎麼產生的

`scripts/sync-showcase.sh` 是唯一的事實來源，以**白名單**方式從私有 repo 複製檔案。

用白名單而不是黑名單，是因為兩者的失敗方向不同：黑名單忘記排除會直接變成洩漏，
而且一旦提交就永久留在 Git 歷史裡；白名單忘記加只會少一個檔案，發現了再補即可。

另外三道防線：

- `copy_dir` 只複製 Git 有追蹤的檔案，未追蹤的權重、資料集與 `.env` 天然被擋在外面。
- `scripts/scrub-docs.py` 在文件複製後移除欄位級規格，並在結束前重新掃描，
  確認沒有殘留資料表或函式名稱，有殘留就讓同步失敗。
- `scripts/scan-secrets.sh` 掃描金鑰、權杖與私鑰樣式。

這個 repo 的 Git 歷史**不是**從私有 repo 匯入的，而是重新開始的，
因此不存在「某次提交誤放、後來刪掉但歷史還查得到」的情況。
